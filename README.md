# Portofolio — Muhamad Ferdiansyah

Infrastructure Engineer — ISP Network Operations, Linux, & Automation.

Portofolio personal berbasis [Astro](https://astro.build) + React + Tailwind CSS. Seluruh konten (pengalaman, proyek, skills, kontak) dikelola dari satu file: `src/data/resume.tsx`.

## Menjalankan secara lokal

```bash
yarn install
yarn dev
```

## Struktur konten

- `src/data/resume.tsx` — data utama: profil, pengalaman kerja, pendidikan, skills (per kategori), proyek, sertifikat, kontak
- `src/data/config.ts` — konfigurasi site, SEO, dan tema
- `src/content/blog/` — artikel teknis (MDX)
- `public/cv-muhamad-ferdiansyah.pdf` — CV 1 halaman ATS-friendly (tautan tombol Download CV)
